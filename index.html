Core System Architecture

Engineered without heavy frameworks using clean OOP patterns and low-level JDBC

⚡

Live Multi-Platform Sync

Direct HTTP client integration fetching live solves, contest ratings, and rank badges from LeetCode (GraphQL), Codeforces (REST), and HackerRank (REST).

🧠

Weakness Recommendation

Custom in-memory recommendation engine using Java's PriorityQueue Max-Heap and topic struggle ratios to surface highest-priority problems.

📊

Synchronized Analytics

Real-time dashboard combining external platform solves with local practice logs, difficulty distributions, and topic completion percentages.

🛡️

Robust JDBC DAO Pattern

Safe parameterized PreparedStatement queries backed by a high-performance HikariCP connection pool, eliminating SQL injection.
